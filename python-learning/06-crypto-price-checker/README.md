# Crypto Price Checker

A simple CoinMarketCap API project that checks the price of one cryptocurrency.

The project uses a coin slug such as `bitcoin`, `ethereum`, or `solana`, and a currency such as `usd`.

## Concepts practiced

- `requests`
- GET requests
- HTTP headers
- API keys
- JSON
- Nested dictionaries/lists
- `input()`

## API key

Set your API key in the environment variable `CMC_API_KEY`.

Windows PowerShell:

```powershell
$env:CMC_API_KEY="YOUR_KEY"
```
