# Number Guessing Game

A guessing game using a random number, difficulty levels, and limited attempts.

## Difficulty

- Easy: 1–50, 5 attempts
- Medium: 1–100, 10 attempts
- Hard: 1–500, 15 attempts

## Concepts practiced

- `random`
- `while`
- `if` / `elif` / `else`
- Input
- Conditions
- Restarting a game
